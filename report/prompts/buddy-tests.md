# Buddy 测试规格提示词

此为补全阶段整理的可复用测试规格，非此前会话逐字历史提示。

针对 Buddy 编写内核断言测试，不能以打印PASS代替检查。除活动管理器的正常分配验证外，从默认Best-Fit借出64页构建隔离Buddy池，测试后恢复管理器并归还原有页面。

检查3页请求实际占4页、分配地址不重叠、引用初值和空闲计数、耗尽返回NULL、超过池大小请求失败、不同顺序释放后计数恢复。选择两个跨伙伴边界的相邻单页释放，确认不能分配2页，证明不错误合并。检查各空闲块对齐、阶大小、空闲标记、总计数与不存在可继续合并的同阶伙伴。恢复原管理器前排空测试池，避免留下空闲标记污染Best-Fit。

运行QEMU验证，并提供脚本在64/128/256MiB环境分别运行Best-Fit和Buddy，遇到panic、缺少检查点或启动未完成都应返回失败。
