# SLUB 实现规格提示词

此为补全阶段整理的可复用规格，非此前会话逐字历史提示。

在现有物理页接口之上实现简化的SLUB风格对象分配器，接口为slub_init、kmalloc(size)、kfree(ptr)。底层通过alloc_pages/free_pages取还页面，不修改老师原有分配器测试。保持默认Best-Fit，允许Buddy模式复用。

按16至2048字节的2次幂尺寸类管理对象。每页头部记录类别、容量、使用数、位图及链表节点，对象按16字节对齐，头部不得覆盖对象。空槽通过位图分配，整页空闲时从链表移除并归还页分配器。较大请求按连续页单独分配，记录原始页数，正确处理长度溢出和分配失败。kmalloc(0)返回NULL，kfree(NULL)无操作。有效指针释放检查槽位边界和位图。

这是体现两层架构的教学实现，非完整Linux SLUB；不宣称具有每CPU缓存、无锁快路径或任意大小无浪费。非法任意地址不保证安全探测，API要求传入仍有效的分配指针。
