# Buddy 实现规格提示词

此为补全阶段整理的可复用规格，非此前会话逐字发送的历史提示；本次实际用户请求是“请你把缺项完成”。

请阅读 pmm.h、memlayout.h、default_pmm.c、best_fit_pmm.c 及 pmm.c，为单核 RISC-V 教学内核实现 Buddy 物理页管理器。保留老师已有测试，默认仍使用 Best-Fit，增加独立的 Buddy 构建和演示入口。

用每阶空闲链表管理 2^order 页，按相对于 pages 的页面索引对齐和 XOR 查找伙伴；初始可用区可能不按最大块对齐，必须分解为若干合法块。合并伙伴必须处于本管理区内、同阶且空闲；不能把相邻但不属于伙伴的块合并。

alloc_pages(n) 向上取整到2的幂，按实际占用扣减计数；free_pages(base,n) 用原始请求页数恢复同一阶块。记录分配块头的实际页数，拒绝不匹配释放。该扩展不提供 Best-Fit 的任意子区间释放语义，报告需明确限制。支持至少当前64/128/256MiB配置，初始化采用一个连续物理区；不设计SMP并发。

提供独立输出目录避免切换编译宏后复用旧对象文件。SLUB应可复用这套页分配接口。
